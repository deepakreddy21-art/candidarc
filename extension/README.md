# CandidArc browser extension

This Manifest V3 extension supports user-opened Greenhouse, Lever, and Ashby application pages. It starts in **Prepare Only** mode; **Autofill and Review** must stop for user review before any submission.

It does not bypass CAPTCHA, collect cookies, store passwords, or submit without the user's action. LinkedIn is not supported for autofill, and the extension does not scrape LinkedIn. Host access is optional and limited to supported ATS domains.
